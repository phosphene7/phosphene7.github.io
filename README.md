## 编辑与发布

直接修改根目录的 index.html 即可更新文字、样式和联系信息。页面使用单个 HTML 文件，图标和样式均内嵌，无需安装依赖或运行构建工具。新增论文或研究方向时，请填入真实信息和有效链接。

Pages 发布设置：Settings → Pages → Deploy from a branch → main → / (root)。提交到 main 后会自动更新，部署状态可在 Actions 查看。

姓名、学校、身份或邮箱变更时，同时更新页面正文、页面标题、description、Open Graph 和 JSON-LD；邮箱应与 OpenReview 资料保持一致。

No tracking, cookies, external fonts, or JavaScript dependencies.
